# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities by opening a [GitHub Private Security Advisory](https://github.com/Ibem-ux/learn-review-chess/security/advisories/new) on `Ibem-ux/learn-review-chess`.

We aim to acknowledge all vulnerability reports within 7 days.

## System Scope & Architecture

Learn Review Chess is a local-first browser application with one server-side proxy to the public Chess.com API and no user accounts or secrets.
